 HR Analytics Dashboard (Power BI)

## 📌 Project Overview

This project analyzes employee data using Microsoft Power BI to identify workforce trends and employee attrition patterns. The dashboard provides interactive visualizations that support HR decision-making.
 Project Objectives

- Analyze employee data
- Identify employee attrition patterns
- Compare attrition across departments and positions
- Build HR KPIs
- Create an interactive HR Analytics Dashboard📊 Dashboard KPIs

- Total Employees: 90
- Employees Left: 26
- Attrition Rate: 28.9%
- Retention Rate: 71.1%
 Dashboard Features

- Attrition by Department
- Attrition by Position
- Employee Distribution by Gender
- Employee Distribution by Department
- Employee Experience Analysis
- Interactive Department and Gender Filters

## 🛠️ Tools Used

- Python
- Pandas
- Microsoft Power BI
- Excel Key Insights

- The organization has an attrition rate of 28.9%.
- The retention rate is 71.1%.
- Attrition varies across departments and job positions.
- The dashboard helps HR identify areas that may require employee retention strategies.
